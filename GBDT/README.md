# GBDT(Gradient Boosting Decision Tree)
현대 머신러닝 알고리즘 기법 중 하나인 **부스팅**의 시작점

* Gradient: 기울기를 통해 손실 최소화
* Boostiong: 약한 모델들을 결합해 점진적으로 강력한 모델을 만든다
* Decision Tree: 그 기본 단위(약한 모델)로 Decision Tree를 사용

## 작동 원리 
이전 모델의 Residual을 다음 모델이 학습하는 과정에 있다.
1. 첫 번째 트리: 전체 데이터의 평균값이나 아주 단순한 기준으로 예측 수행(당연하게도 오차가 큼)
2. Residual 계산: 실제값과 예측값의 차이(오차)를 구한다.
3. 두 번째 트리: 원본 데이터(x)를 보고 실제값(y)를 맞추는 게 아니라, 첫 번째 나무가 틀린 Residual을 맞추도록 학습
4. 이 과정을 반복하며 Residual을 계속해서 줄여나간다.
* Gradient가 붙은 이유
  * 예측 성능을 평가하는 손실함수 $L(y, \hat{y})$가 있을 때, 이 함수를 미분하여 얻은 기울기의 반대 방향으로 모델을 업데이트한다.
  * 즉, 잔차를 학습하는 것 = 손실 함수의 그라디언트를 줄이는 방향으로 나무를 추가하는 것 이라고 볼 수 있겠다.
* 장점
  * 높은 예측력: 정형 데이터(표 형태)에서 뛰어난 성능을 보인다.
  * 유연성: 다양한 손실 함수를 사용할 수 있어 분류와 회귀 모두에 능하다.
* 단점
  * 느린 속도: 나무를 하나씩 순차적으로 만들기 때문에 병렬처리가 어렵고 학습 기간이 길다.
  * Overfitting: 나무를 너무 많이 쌓으면 학습 데이터에만 지나치게 최적화될 수 있다.
  * 이를 해결할 모델 **XGBoost**
