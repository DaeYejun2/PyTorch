## LSTM AutoEncoder(AE)의 원리 이해하기
일반적인 LSTM은 다음에 올 값이 정상인지 이상인지를 맞춘다면, 
LSTM AE는 입력 데이터를 압축하고 있는 의미 있는 표현으로 인코딩한 
다음 복원시켜 복원된 데이터가 원본 데이터와 최대한 유사하도록 만든 신경망이다.

AE를 이용한 이상 탐지 기법은 개념적으로는 간단하다. 만약 정상 데이터로만 AE를 학습하면 원본 데이터와 복원 데이터의 차이인 
복원손실 또는 복원오차는 매우 작을 것이다.

하지만 학습된 모델에, 학습에 사용한 데이터와 상이한 특성을 갖는 데이터가 입력된다면 이 데이터는 학습되지 않았기 때문에
복원된 데이터는 원본 데이터와 많은 차이가 발생할 것이다. 이 복원오차가 정해진 임계치를 넘게 되면 이상으로 판정하는 것이다.

이러한 방법을 시퀸스 또는 시계열 데이터에 적용한 것이 LSTM-AE 이상 탐지 모델이다. LSTM-AE는 인코더와 디코더에 LSTM 신경망을 적용한 오토인코더다.

## LSTM Vs LSTM-AE
LSTM은 지도학습으로 Label이 있어야 한다. 학습 데이터 안에서 성능이 매우 뛰어나지만 학습하지 않은 새로운 유형의 불량은 잡지 못한다는 단점이 있다. 실제 현장에서도 데이터 라벨링이 잘 된 곳에 사용된다.

LSTM-AE는 비지도 학습으로 정답 없이도 정상 데이터만 있으면 된다. 처음 보는 형태의 고장도 잡아낼 수 있지만, 학습(복원) 자체가 매우 어렵다. 라벨링이 거의 없는 실제 공장에서 필수적으로 사용한다.

* 스케일링이란
  * 서로 다른 단위와 범위를 가진 데이터들을 일정한 규칙에 따라 맞추는 작업
  * 압력 센서(1000 ~ 2000 pa), 온도 센서(20 ~ 30℃) -> 이 상태로 LSTM에 넣으면, 모델은 숫자가 큰 압력 센서가 더 중요한 정보라고 오해하게 되고 온도의 미세한 변화는 압력의 변화에 묻혀버리게 된다. 이를 방지하기 위해 모든 데이터를 0~1 사이나 평균 0, 표준편차 1의 동일한 범위에서 뛰게 만드는 것.
* 주요 스케일링 기법
  * StandardScaler (표준화): 평균을 0, 분산을 1로 만든다. 데이터가 종 모양(가우시안 분포)일 때 효과적이며, 이상치에 조금 더 강하다.(현재 코드에서 사용중인)
  * MinMaxScaler (정규화): 모든 값을 0과 1 사이로 압축. 데이터의 최소/최대값이 명확할 때 좋다.
 
## 시계열 윈도우
```
def create_sequences(data, seq_length):
  sequence = []
  for i in range(len(data) - seq_length + 1):
    seq = data[i:i+seq_length]
    sequence.append(seq)
  return np.array(sequence)

seq_length = 5
data_3d = create_sequences(data_scaled, seq_length)
print(data_3d.shape)

# (1563, 5, 590)

X_tensor = torch.FloatTensor(data_3d)

dataset = TensorDataset(X_tensor)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)

for batch in dataloader:
  print(batch[0].shape)
  break

# torch.Size([32, 5, 590])
# 전체 공정 횟수에서 윈도우 크기만큼 줄어든 샘플 개수 | 한 번에 모델이 볼 데이터 길이 | 센서의 개수
```

* 데이터를 시계열 형태로 조립하는 과정
* LSTM은 단일 데이터가 아니라 흐름을 본다. create_sequences 함수는 긴 데이터를 seq_length만큼 잘라서 옆으로 한칸씩 밀어가며 묶음을 만든다.
  * 단순히 현재 센서 값만 보는게 아니라, 방금 전 5단계 공정의 흐름을 학습시키기 위함.
* 시퀸스 길이를 설정하는 이유
  * 반도체 공정에서 갑자기 불량이 발생하는 경우는 드물다. 보통 온도가 서서히 올라가거나, 압력이 조금씩 흔들리는 등의 전조 현상이 먼저 나타난다.
  * 시퀸스 길이를 1로 하면 지금 이 순간의 센서값(일반 머신러닝)만 보지만, 길이를 5로 하면 최근 5번의 흐름을 보고 다음 상태를 파악할 수 있다.
  * 즉, 과거의 데이터 흐름을 통해 미래를 예측하기 위해 사용한다.

## LSTM-AE
590개의 센서 데이터를 64차원 정도로 압축했다가 복원.

### 모델 정의
```
class LSTM_AE(nn.Module):
  def __init__(self, input_dim, hidden_dim, num_layer=1):
    super(LSTM_AE, self).__init__()
    self.hidden_dim = hidden_dim

    # Encoder: (Batch, Seq, Input) -> (Batch, Hidden)
    self.encoder = nn.LSTM(input_dim, hidden_dim, num_layers=num_layer, batch_first=True)

    # Decoder: (Batch, Seq, Hidden) -> (Batch, Seq, Input)
    self.decoder = nn.LSTM(hidden_dim, hidden_dim, num_layer, batch_first=True)
    self.fc = nn.Linear(hidden_dim, input_dim)

  def forward(self, x):
    batch_size, seq_len, _ = x.size()

    # 1. Encoding
    _, (hidden, _) = self.encoder(x)
    # hidden shape: (num_layers, batch, hidden_dim)

    # 2. Decoding 준비: Encoder의 마지막 hidden state를 seq_len만큼 반복
    # (batch, hidden_dim) -> (batch, 1, hidden_dim) -> (batch, seq_len, hidden_dim)
    z = hidden[-1].unsqueeze(1).repeat(1, seq_len, 1)

    # 3. Decoding
    decoder_out, _ = self.decoder(z)

    # 4. 원래 차원(590)으로 복원
    out = self.fc(decoder_out)
    return out

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = LSTM_AE(input_dim = 590, hidden_dim=64).to(device)
```
* __init__
  * input_dim (590): 반도체 장비에 달린 590개의센서
  * hidden_dim (64): 590개의 복잡한 데이터를 64개의 핵심 특징으로 압축하겠다는 뜻. (예: 압력, 온도 등의 상관관계를 요약한 핵심 정보)
  * self.encoder: 데이터를 압축하는 역할
  * self.decoder: 압축된 정보를 다시 원래의 590개 센서 값으로 복구하는 역할
* forward (작동 원리)
  * Encoding: 5초(seq_len) 동안의 센서 흐름을 보고 최종적인 상태 요약본(hidden)을 만들어 준다.
  * Repeat: 그 요약본을 다시 5초 분량으로 복사해 Decoder에게 전달. 이 요약본을 토대로 다시 5초간 복원시키도록 하는 것
  * Decoding & Fc: 요약본에서 다시 590개의 숫자를 복원해낸다.

```
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

epochs = 50
model.train()

for epoch in range(epochs):
  train_loss = 0
  for batch in dataloader:
    x = batch[0].to(device)

    optimizer.zero_grad() # 매번 새로운 데이터에서

    output = model(x) # 모델에게 데이터를 보여주고 똑같이 복사해보라고 하는 단계

    loss = criterion(output, x)

    loss.backward() # 역전파로 어느 부분 수정해야할지 찾는 과정
    optimizer.step() # 찾은 원인을 바탕으로 모델 내부의 파라미터 수정 

    train_loss += loss.item()

  if (epoch+1) % 10 == 0:
        print(f"Epoch [{epoch+1}/{epochs}], Loss: {train_loss/len(dataloader):.6f}")
```
## 이상치 판정 및 분석

#### 복원 오차 계산
```
model.eval()
reconstruction_errors = []

with torch.no_grad():
  for batch in dataloader:
    x = batch[0].to(device)
    output = model(x)

    # 각 샘플별로 MSE(평균 제곱 오차) 계산
    # batch, seq, feature -> batch
    loss = torch.mean(torch.pow(x - output, 2), dim=(1, 2))
    reconstruction_errors.extend(loss.cpu().numpy())

reconstruction_errors = np.array(reconstruction_errors)
```

* 이상치 샘플 골라내기
  * np.where(...): 앞서 설정한 기준선(threshold)보다 오차가 큰 데이터들의 위치(인덱스)를 다 찾는다. 그중 첫 번째([0][0])를 분석 대상으로 삼겠다는 뜻.
  * unsqueeze(0): 모델은 항상 '묶음(Batch)' 단위로 입력받기를 원한다. 데이터 하나만 넣더라도 (1, 5, 590)처럼 묶음 형태의 차원을 강제로 만들어주는 작업.
  * output = model(sample): 선택한 이상치 데이터를 모델에 넣어 복원을 시도.
 
* 센서별 범인 찾기
  * sample - output: 원본 값과 모델이 복원한 값의 차이를 구한다.
  * torch.pow(..., 2): 차이값을 제곱하여 모두 양수로 만든. (오차의 크기)
  * dim=1: 현재 데이터는 (1, 5, 590). 여기서 1번 차원은 시간(5초)이다. 5초 동안 발생한 오차를 평균 내어, 각 센서당 하나의 오차 점수만 남긴다. 결과는 (590)개의 숫자가 된다.
  * squeeze()...: 불필요한 차원을 없애고 넘파이 배열로 변환.

## 초기 모델의 문제점 및 진단
처음 모델을 돌렸을 때 Loss가 줄어들지 않고 그래프가 직선에 가깝게 나왔던 원인은 다음과 같다.
<br>
* 590개의 복잡한 데이터를 너무 작은 차원(64)로 압축하려다 보니 주요 패턴이 모두 파괴
* 정상 데이터뿐만 아니라 이상치까지 모두 학습에 참여시켜 모델이 무엇이 정상인지 정의하지 못함
* 인코더의 마지막 상태만 반복해서 디코더에 넣는 방식으로는 시계열의 역동적인 변화를 복원하는데 한계가 있었다.

#### 개선 항목
* 모델 용량 확대: Hidden 64 / 1Layer -> Hidden 256 / 2~3 Layer
* 데이터 순도 개선: 전체 데이터 학습 -> 정상(Label 0)데이터만 학습 - 모델이 정상 공정의 패턴을 완벽하게 학습
* 디코더 입력 강화: 단순 RepeatVector -> 초기 상태(h, c) 전달 - 시점별 센서 값의 급격한 변화 복원 가능

### 전체 코드

#### 데이터 로드 및 정상 데이터만 추출
```
import pandas as pd
import numpy as np
import torch
import torch.nn as nn
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from torch.utils.data import TensorDataset, DataLoader

# 1. 데이터 로드
url = "https://archive.ics.uci.edu/ml/machine-learning-databases/secom/secom.data"
label_url = "https://archive.ics.uci.edu/ml/machine-learning-databases/secom/secom_labels.data"

data = pd.read_csv(url, sep=" ", header=None)
labels = pd.read_csv(label_url, sep=" ", header=None)

# 전처리: 결측치 평균 채우기 및 라벨 변경 (-1 -> 0, 1 -> 1)
data = data.fillna(data.mean())
y = labels[0].replace(-1, 0).values

# 스케일링
scaler = StandardScaler()
data_scaled = scaler.fit_transform(data)

# 2. 시계열 윈도우 생성 함수
def create_sequences(data, seq_length):
    sequences = []
    for i in range(len(data) - seq_length + 1):
        sequences.append(data[i:i+seq_length])
    return np.array(sequences)

seq_length = 10  # 흐름을 더 잘 보려고 10으로
data_3d = create_sequences(data_scaled, seq_length)
y_adjusted = y[seq_length-1:] # 시퀀스 길이에 맞춰 라벨도 자르기

# 3. 학습 데이터 분리 (정상 데이터만 학습에 사용)
normal_idx = np.where(y_adjusted == 0)[0]
X_train_tensor = torch.FloatTensor(data_3d[normal_idx])

# DataLoader 설정
dataloader = DataLoader(TensorDataset(X_train_tensor), batch_size=64, shuffle=True)
```

#### LSTM-AE 모델 정의 및 학습
```
# 4. 모델 정의
class LSTM_AE_Improved(nn.Module):
    def __init__(self, input_dim, hidden_dim, num_layer=2):
        super(LSTM_AE_Improved, self).__init__()
        # Encoder: 더 깊고 넓게
        self.encoder = nn.LSTM(input_dim, hidden_dim, num_layers=num_layer, batch_first=True, dropout=0.1)
        
        # Decoder: 인코더와 대칭 구조
        self.decoder = nn.LSTM(hidden_dim, hidden_dim, num_layers=num_layer, batch_first=True, dropout=0.1)
        self.fc = nn.Linear(hidden_dim, input_dim)

    def forward(self, x):
        batch_size, seq_len, _ = x.size()
        
        # Encoding
        # h_n은 마지막 레이어의 hidden state (num_layers, batch, hidden_dim)
        _, (h_n, c_n) = self.encoder(x)
        
        # Decoding 준비: 반복적인 입력 대신 context를 유지하며 복원
        # 시퀀스 길이만큼 펼쳐줌
        decoder_input = h_n[-1].unsqueeze(1).repeat(1, seq_len, 1)
        
        # 디코더의 초기 상태를 인코더의 마지막 상태로 전달
        decoder_out, _ = self.decoder(decoder_input, (h_n, c_n))
        
        out = self.fc(decoder_out)
        return out


# 모델 생성
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
input_dim = data_scaled.shape[1]
model = LSTM_AE_Improved(input_dim=590, hidden_dim=512, num_layer=2).to(device)

# 손실함수 및 최적화
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 5. 학습 시작
epochs = 150
model.train()

for epoch in range(epochs):
    train_loss = 0
    for batch in dataloader:
        x = batch[0].to(device)
        optimizer.zero_grad()
        output = model(x)
        loss = criterion(output, x)
        loss.backward()
        optimizer.step()
        train_loss += loss.item()
    
    if (epoch+1) % 10 == 0:
        print(f"Epoch [{epoch+1}/{epochs}], Loss: {train_loss/len(dataloader):.6f}")
```
