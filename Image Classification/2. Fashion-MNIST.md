# Fashion-MNIST

## 1. Fashion-MNIST 데이터셋
MNIST와 동일하게 60,000개의 학습 이미지와 10,000개의 테스트 이미지로 구성되어 있으며, 이미지 크기도 28x28 픽셀의 흑백 이미지로 동일하다.
<br>
단순 손글씨 숫자 대신 10가지 종류의 의류 이미지로 이루어져 있어, MNIST보다 훨씬 복잡하고 현실적인 데이터 셋이다.

## 2. Fashion-MNIST 분류하기

### 1. 데이터 준비
torchvision.datasets에서 MNIST 대신 FashionMNIST로 변경
```
import torch
import torchvision
import torchvision.transforms as transforms

# 텐서로 변환하고 정규화하는 변환기 정의
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# 학습 및 테스트 데이터셋 불러오기 (FashionMNIST로 변경)
train_dataset = torchvision.datasets.FashionMNIST(root='./data', train=True, download=True, transform=transform)
train_loader = torch.utils.data.DataLoader(train_dataset, batch_size=64, shuffle=True)

test_dataset = torchvision.datasets.FashionMNIST(root='./data', train=False, download=True, transform=transform)
test_loader = torch.utils.data.DataLoader(train_dataset, batch_size=64, shuffle=False)
```

### 2. 모델 설계
Fashion-MNIST는 MNIST보다 더 복잡한 특징을 가지고 있으므로, 모델의 은닉층을 더 깊게 만들어 성능을 높여보겠다.
```
import torch.nn as nn
import torch.nn.functional as F

class MLP(nn.Module):
  def __init__(self):
    super().__init__()
    # 입력층: 784
    self.fc1 = nn.Linear(784, 256) # 뉴런 수를 128 -> 256으로 늘림
    # 은닉층: 1
    self.fc2 = nn.Linear(256, 128)
    # 은닉층: 2
    self.fc3 = nn.Linear(128, 64)
    # 출력층: 10
    self.fc4 = nn.Linear(64, 10)
  def forward(self, x):
    x = x.view(-1, 28*28)
    x = F.relu(self.fc1(x))
    x = F.relu(self.fc2(x))
    x = F.relu(self.fc3(x))
    x = self.fc4(x)
    return x
```

### 3 & 4. 손실 함수, 옵티마이저 정의 및 학습
```
model = MLP()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# loss 값을 저장할 빈 리스트 만들기
loss_history = []

# 학습 루프
num_epochs = 10
for epoch in range(num_epochs):
  running_loss = 0.0
  for i, data in enumerate(train_loader):
    inputs, labels = data

    # 순전파
    outputs = model(inputs)
    loss = criterion(outputs, labels)

    # 역전파
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    running_loss += loss.item()
  # 한 epoch이 끝날 때마다 평균 loss를 리스트에 담기
  epoch_loss = running_loss / len(train_loader)
  loss_history.append(epoch_loss)

  print(f'epoch [{epoch+1}/{num_epochs}], loss: {epoch_loss:.4f}')
print("학습 완료")
```

### 5. 모델 평가
```
correct = 0
total = 0
with torch.no_grad():
  for data in test_loader:
    images, labels = data
    outputs = model(images)
    _, predicted = torch.max(outputs.data, 1)
    total += labels.size(0)
    correct += (predicted == labels).sum().item()

print(f'\n테스트 데이터셋에서 모델의 정확도: {100 * correct / total:.2f}%')
```
