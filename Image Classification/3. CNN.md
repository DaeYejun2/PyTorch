# CNN(Convolution Nerual Network)

## before starting
MLP는 이미지의 픽셀을 1차원 벡터로 펼치기 때문에, 이미지의 가장 중요한 특징인 공간적 구조(Spatial Structure)를 잃는다는 한계가 있다.
이 한계를 극복하고 이미지 인식 분야에서 혁신을 일으킨 CNN, 합성곱 신경망의 원리와 활용법을 알아보겠다.

## 1. CNN(합성곱 신경망)
* 특징 추출(Feature Extraction)블록: 이미지의 공간적 특징을 추출하는 역할을 한다.
* 분류(Classification)블록: 추출된 특징을 바탕으로 이미지를 분류하는 역할을 한다.

## 2. 특징 추출 블록의 핵심 연산

### 1. 합성곱(Convolution) 연산
합성곱 연산은 **필터** 또는 **커널**이라고 불리는 작은 행렬을 이미지 위에 슬라이딩하면서 이미지의 특징을 추출하는 과정이다.
<br>
* 필터: 이미지의 특정 특징(수직선, 수평선, 모서리 등)을 감지하는 역할을 한다.
* 특징 맵: 합성곱 연산의 결과로 생성된 새로운 이미지이다. 이 특징 맵은 원본 이미지의 특징이 어디에 있는지 보여준다.
<br>
예를 들어, 수직선 필터를 사용하면 원본 이미지에서 수직선 특징이 있는 부분만 강조되어 특징 맵으로 나타난다. CNN은 학습을 통해 데이터에 가장 적합한 필터의 가중치를 스스로 찾아낸다.

### 2. 활성화 함수
함성곱 연산의 결과에 비선형성을 추가하기 위해 활성화 함수 적용.
<br>
이미지 특징의 복잡도를 높이는 역할을 하며, 주로 **ReLu** 함수가 사용된다.

### 3. 풀링(Pooling) 연산
특징 맵의 크기를 줄여(다운샘플링) 계산량을 줄이고, 모델의 과적합(Overfitting)을 방지하는 역할을 한다. 또한, 민감도를 줄여 이미지의 위치가 약간 변하더라도 동일한 특징으로 인식하게 만든다.
<br>
* Max Pooling: 풀링 윈도우 내에서 가장 큰 값만 남긴다. 주로 사용되는 방식

## 3. CNN 모델 만들기
MLP와 달리 이미지의 공간적 구조를 그대로 유지한 채 Conv2d와 MaxPool2d 모듈을 사용해 모듈 구성
```
import torch
import torch.nn as nn
import torch.nn.functional as F

class CNN(nn.Module):
  def __init__(self):
    super().__init__()
    # 특징 추출 블록
    # 첫 번째 합성곱 층: 입력 채널 1, 출력 채널 32, 커널 크기 3x3
    self.conv1 = nn.Conv2d(1, 32, 3)
    # 두 번째 합성곱 층: 입력 채널 32, 출력 채널 64, 커널 크기 3x3
    self.conv2 = nn.Conv2d(32, 64, 3)

    # 첫 번째 맥스 풀링 층: 커널 크기 2x2, stride: 2
    self.pool1 = nn.MaxPool2d(2, 2)
    self.pool2 = nn.MaxPool2d(2, 2)

    # 분류 블록
    # 합성곱층을 통과한 이미지 크기를 계산해야 한다
    # 28->26->13->11->5
    # 최종 특징 맵의 크기: 64 채널 x 5x5
    self.fc1 = nn.Linear(64*5*5, 128)
    self.fc2 = nn.Linear(128, 10)

  def forward(self, x):
    # 특징 추출
    x = self.pool1(F.relu(self.conv1(x)))
    x = self.pool2(F.relu(self.conv2(x)))

    # 텐서를 1차원으로 펼치기 (평탄화)
    x = torch.flatten(x, 1)

    # 분류
    x = F.relu(self.fc1(x))
    x = self.fc2(x)
    return x
```
* nn.Conv2d: 2차원 이미지에 대한 합성곱 연산을 수행
* in_channels: 입력 이미지의 채널 수. 흑백 이미지이므로 1
* out_channels: 출력할 특징 맵의 수
* kernel_size: 필터의 크기
* nn.MaxPool2d: 2차원 이미지에 대한 맥스 풀링 연산 수행
* torch.flatten: 특징 추출 블록에서 나온 다차원 텐서를 1차원으로 펼쳐 분류 블록의 입력으로 사용

## 4. Fashion-MNIST 분류 by CNN model
MLP와 달리 공간적 구조를 그대로 유지한 채 Conv2d와 MaxPool2d 모듈을 사용해 모델 구성
### 1. 데이터 준비
Fashion-MNIST 데이터셋 불러오고 Transform 적용
```
import torch
import torchvision
import torchvision.transforms as transforms
from torch.utils.data import DataLoader
import torch.nn as nn
import torch.nn.functional as F

# 텐서로 변환하고 정규화하는 변환기 정의
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,),(0.5,))
])

# 학습 및 테스트 데이터셋 불러오기
train_dataset = torchvision.datasets.FashionMNIST(root='./data', train=True, download=True, transform=transform)
test_dataset = torchvision.datasets.FashionMNIST(root='./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)
```
### 2. 모델 설계
Fashion-MNIST 이미지의 크기는 28x28. 이미지의 채널은 흑백이므로 1.
```
class CNN(nn.Module):
  def __init__(self):
    super().__init__()
    # 첫 번째 특징 추출 블록
    self.conv1 = nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3, padding=1)
    self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)

    # 두 번째 특징 추출 블록
    self.conv2 = nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3, padding=1)
    self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)

    # 분류 블록 (MLP와 동일)
    # 합성곱층을 통과한 이미지 크기를 계산해야 합니다.
    # 입력: (1, 28, 28)
    # conv1 통과: (32, 28, 28) -> padding=1이므로 크기 유지
    # pool1 통과: (32, 14, 14) -> 크기 절반
    # conv2 통과: (64, 14, 14) -> padding=1이므로 크기 유지
    # pool2 통과: (64, 7, 7) -> 크기 절반
    self.fc1 = nn.Linear(64*7*7, 128)
    self.fc2 = nn.Linear(128, 10)

  def forward(self, x):
    # 특징 추출
    x = self.pool1(F.relu(self.conv1(x)))
    x = self.pool2(F.relu(self.conv2(x)))

    # 텐서를 1차원으로 펼치기 (평탄화)
    x = torch.flatten(x, 1)

    # 분류
    x = F.relu(self.fc1(x))
    x = self.fc2(x)
    return x
```

## 3 & 4. 손실 함수, 옵티마이저 정의 및 학습
```
# 모델, 손실 함수, 옵티마이저 정의
model = CNN()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 학습 루프
num_epochs = 10
for epoch in range(num_epochs):
  running_loss = 0.0
  for i, data in enumerate(train_loader):
    inputs, labels = data

    # 순전파
    outputs = model(inputs)
    loss = criterion(outputs, labels)

    # 역전파
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    running_loss += loss.item()

  print(f'에포크 [{epoch+1}/{num_epochs}], 손실: {running_loss/len(train_loader):.4f}')
print("학습 완료!")
```

## 5. 모델 평가
```
correct = 0
total = 0
with torch.no_grad():
    for data in test_loader:
        images, labels = data
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

print(f'\n테스트 데이터셋에서 모델의 정확도: {100 * correct / total:.2f}%')
```
