# 데이터 증강, 모델 성능 높이기

### before starting
CNN모델은 학습 데이터에만 너무 잘 맞고 새로운 데이터에 대해서는 성능이 떨어지는 과적합 문제를 해결하기 위해 데이터 증강을 사용해 보겠다.

## 1. 데이터 증강
원본 데이터에 인위적인 변형을 가해 학습 데이터의 양을 늘리는 기술
<br>
이를 통해 모델은 다양한 각도, 크기, 밝기, 등의 데이터를 미리 경험하게 되어, 실제 세상의 다양한 이미지에 대한 일반화 능력을 향상시킬 수 있다.
<br>
ex) 고양이 이미지를 인식하는 모델을 학습시킬 때, 원본 이미지 외에도 좌우 반전, 회전, 밝기 변경 등을 적용한 여러 이미지를 추가로 학습시킬 수 있다.

## 2. PyTorch에서 데이터 증강 적용
torchvision.transforms 모듈은 다양한 데이터 증강 기술을 제공하여, 매우 쉽게 적용할 수 있다

### 대표적인 데이터 증강 기법
* transforms.RandomHorizontalFlip(): 이미지를 50% 확률로 좌우 반전
* transforms.RandomRotation(degrees): 이미지를 무작위 각도로 회전
* transforms.ColorJitter(brightness, contrast, saturation, hue): 밝기, 대비, 채도 등을 무작위로 변경
* transforms.RandomCrop(size): 이미지의 일부를 무작위로 잘라낸다
* transforms.Resize(size): 이미지 크기를 조절

### Fashion-MNIST에 데이터 증강 적용
**학습 데이터셋에만 데이터 증강 적용**
<br>
**테스트 데이터는 모델의 실제 성능을 평가하기 위한 것이므로 원본 상태를 유지해야 한다.**
```
from torch.utils import data
import torch
import torchvision
import torchvision.transforms as transforms
from torch.utils.data import DataLoader
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim

# 1. 데이터 증강 변환기 정의 (학습 데이터용)
train_transform = transforms.Compose([
    transforms.RandomRotation(15), # 무작위로 15도 회전
    transforms.RandomHorizontalFlip(), # 50% 확률로 좌우 반저
    transforms.ToTensor(),
    transforms.Normalize((0.5,),(0.5,))
])

# 테스트 데이터는 증강하지 않는다
test_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,),(0.5,))
])

# 2. 데이터셋 및 데이터로더 불러오기
train_dataset = torchvision.datasets.FashionMNIST(root='./data', train=True, download=True, transform=train_transform)
train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)

test_dataset = torchvision.datasets.FashionMNIST(root='./data', train=False, download=True, transform=test_transform)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)

# 3. 모델 정의 (이건 이전 CNN 모델과 동일)
class CNN(nn.Module):
  def __init__(self):
    super().__init__()
    self.conv1 = nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3, padding=1)
    self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
    self.conv2 = nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3, padding=1)
    self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
    self.fc1 = nn.Linear(64 * 7 * 7, 128)
    self.fc2 = nn.Linear(128, 10)

  def forward(self, x):
    x = self.pool1(F.relu(self.conv1(x)))
    x = self.pool2(F.relu(self.conv2(x)))
    x = torch.flatten(x, 1)
    x = F.relu(self.fc1(x))
    x = self.fc2(x)
    return x

# 4. 모델 학습 및 평가
model = CNN()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

num_epochs = 2
for epoch in range(num_epochs):
  for i, data in enumerate(train_loader):
    inputs, labels = data
    outputs = model(inputs)
    loss = criterion(outputs, labels)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
  print(f'epoch [{epoch+1}/{num_epochs}], loss: {loss.item():.4f}')

correct = 0
total = 0
with torch.no_grad():
  for data in test_loader:
    images, labels = data
    outputs = model(images)
    _, predicted = torch.max(outputs.data, 1)
    total += labels.size(0)
    correct += (predicted == labels).sum().item()

print(f'\n테스트 데이터셋에서 모델의 정확도: {100 * correct / total:.2f}%')
```
**데이터 증강을 적용하면 적용하지 않았을 때보다 최종 정확도가 더 높에 나올 가능성이 크다**
